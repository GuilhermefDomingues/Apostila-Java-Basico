# Exercícios da Apostila Java Básico

Este repositório reúne minhas resoluções dos exercícios da apostila Java Básico. Usei as atividades para praticar a sintaxe da linguagem e a lógica de programação.

## Como executar

1. No GitHub, clique em **Code → Download ZIP** e extraia os arquivos.
2. Abra a pasta do projeto no IntelliJ IDEA.
3. Abra a classe do exercício que deseja testar e clique em **Run** ao lado do método `main`.
